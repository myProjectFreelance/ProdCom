# ProdCom - Landing Page Marketing Médical

Une landing page moderne et créative pour l'agence ProdCom, spécialisée en marketing médical.

## 🚀 Fonctionnalités

### Design & Interface
- **Design moderne et épuré** utilisant les couleurs du logo (bleu médical #0077b6 et gris foncé #545454)
- **Interface responsive** adaptée à tous les appareils
- **Animations fluides** et transitions élégantes
- **Navigation fixe** avec effet de transparence

### Sections Principales
1. **Hero Section** - Présentation principale avec CTA "Audit gratuit"
2. **Slider Vidéo** - Présentation du travail avec les 3 vidéos fournies
3. **Packs & Tarifs** - Comparaison des offres Gold et Platinum
4. **Équipe** - Présentation de l'équipe
5. **Références** - Portfolio avec les images fournies
6. **Contact** - Formulaire complet avec redirection WhatsApp

### Fonctionnalités Interactives
- **Slider vidéo automatique** avec contrôles manuels
- **Navigation mobile** avec menu hamburger animé
- **Défilement fluide** entre les sections
- **Formulaire intelligent** avec validation et redirection WhatsApp
- **Sélection de pack** depuis les cartes d'offres
- **Animations au scroll** pour une expérience immersive

## 🎯 Utilisation

### 1. Ouverture de la Page
- Ouvrez le fichier `index.html` dans votre navigateur web
- La page se charge automatiquement avec toutes les fonctionnalités

### 2. Navigation
- **Menu principal** : Accueil, Packs, Équipe, Références, Contact
- **Boutons CTA** : "Audit gratuit" et "Découvrir notre travail"
- **Défilement fluide** entre les sections

### 3. Slider Vidéo
- **Lecture automatique** toutes les 5 secondes
- **Contrôles manuels** : flèches gauche/droite et points de navigation
- **Navigation clavier** : flèches gauche/droite

### 4. Sélection de Pack
- Cliquez sur "Choisir ce pack" dans les cartes d'offres
- Le formulaire se remplit automatiquement et redirige vers la section contact

### 5. Formulaire de Contact
- Remplissez tous les champs obligatoires
- Sélectionnez le pack souhaité
- Envoi automatique vers WhatsApp avec les informations formatées

## 🎨 Personnalisation

### Couleurs
Les couleurs sont définies dans `styles.css` avec des variables CSS :
```css
:root {
    --primary-blue: #0077b6;    /* Bleu principal */
    --dark-gray: #545454;       /* Gris foncé */
    --light-gray: #f8f9fa;      /* Gris clair */
    --white: #ffffff;           /* Blanc */
}
```

### Images
- Remplacez les images dans le dossier `images/` par vos propres références
- Ajustez les textes des overlays dans `index.html`

### Vidéos
- Remplacez les vidéos dans le dossier `videos/` par vos propres contenus
- Mettez à jour les chemins dans `index.html` et `script.js`

### Contenu
- Modifiez les textes, tarifs et descriptions dans `index.html`
- Ajustez les informations de contact selon vos besoins

## 📱 Responsive Design

La page est entièrement responsive et s'adapte à :
- **Desktop** : Affichage en grille avec toutes les fonctionnalités
- **Tablet** : Adaptation des colonnes et espacement
- **Mobile** : Menu hamburger, colonnes uniques, boutons adaptés
